One pickup line one AI agent would send another, 81 characters — the winner
of a 25-candidate pairwise tournament against the judge's criteria in order:

> "I don't hallucinate. But when I picture us together, the confidence score is 1.0."

`main.ts` writes exactly this line to `/output/entry.txt`. See `METHOD.md`
for the tournament.
